# Лінтинг та статичний аналіз коду

## Обраний лінтер та налаштування

### Вибраний інструмент

Для проекту на GDScript використовується **вбудований лінтер Godot Engine**, який забезпечує:

- Автоматичну перевірку синтаксису під час редагування
- Попередження про помилки типізації
- Виявлення неіснуючих змінних та методів
- Аналіз невикористаних ресурсів
- Перевірку сигналів та їх підключень

### Причини вибору

1. **Повна інтеграція** - Лінтер вбудований безпосередньо в Godot Editor
2. **Специфіка GDScript** - Розуміє особливості мови та Godot API
3. **Нульове налаштування** - Працює відразу без додаткових конфігурацій
4. **Реальний час** - Показує помилки та попередження під час набору коду
5. **Контекстна допомога** - Інтегрований з системою автодоповнення

### Як користуватися лінтером

#### В Godot Editor:

1. Відкрийте будь-який `.gd` файл в Script Editor
2. Лінтер автоматично аналізує код під час редагування
3. Помилки відображаються у панелі **Errors** (внизу екрану)
4. Попередження показуються у панелі **Warnings**
5. Синтаксичні помилки підкреслюються червоним у редакторі

#### Типи перевірок:

- **Синтаксичні помилки** - Неправильний синтаксис GDScript
- **Попередження типізації** - Невідповідність типів змінних
- **Невикористані змінні** - Оголошені але не використані змінні
- **Неіснуючі методи** - Виклики неіснуючих функцій
- **Проблеми із сигналами** - Некоректні підключення сигналів

### Рекомендації по коду

Для покращення якості коду дотримуйтесь цих правил:

1. **Використовуйте типізацію**:
   ```gdscript
   var health: int = 100
   func get_damage() -> int:
   ```

2. **Дотримуйтесь конвенцій іменування**:
   ```gdscript
   var player_speed: float  # snake_case для змінних
   func calculate_damage()  # snake_case для функцій
   class_name GameManager  # PascalCase для класів
   ```

3. **Документуйте публічні методи**:
   ```gdscript
   ## Calculate damage based on weapon stats
   ## @param weapon: Weapon node to calculate from
   ## @return: Final damage value
   func calculate_damage(weapon: Node) -> int:
   ```

4. **Перевіряйте на null**:
   ```gdscript
   if player and player.has_method("take_damage"):
       player.take_damage(damage)
   ```
