Diploma Game Project Documentation
====================================

Документація для дипломного проекту 3D Action Game на Godot Engine 4.2.1.

Огляд проекту
=============

Цей 3D action game демонструє сучасні концепції розробки ігор:

* **Динамічна генерація рівнів** - процедурне створення контенту
* **ШІ ворогів** - система спавну хвиль з прогресивною складністю
* **Система збереження** - збереження стану гри в JSON
* **Фізичний бій** - реалістичне управління та бойова механіка

Основні компоненти
==================

GameManager
-----------

Центральний координатор всіх ігрових систем:

* Управління станом гри
* Обробка вводу користувача
* Координація між підсистемами
* Управління камерою та UI

LevelSpawner
------------

Система спавну ворогів з прогресивною складністю:

* Хвильовий спавн ворогів
* Масштабування складності
* Управління припасами
* Детекція завершення рівня

SaveManager
-----------

Система збереження стану гри:

* Серіалізація в JSON формат
* Збереження позицій гравця та ворогів
* Відновлення налаштувань рівня
* Обробка помилок файлової системи

Швидкий старт
=============

1. **Відкрийте проект в Godot Engine 4.2.1**
2. **Натисніть F5 для запуску гри**
3. **Управління**:

   * WASD - рух гравця
   * Миша - прицілювання
   * ЛКМ - стрільба
   * R - регенерація рівня
   * F5 - збереження гри
   * F9 - завантаження гри

Вимоги до системи
=================

**Для розробки:**

* Godot Engine 4.2.1+
* 8GB RAM мінімум
* OpenGL 3.3 сумісна відеокарта

**Для запуску:**

* Windows 10+, macOS 10.14+, або Linux з OpenGL 3.3
* 4GB RAM мінімум
* 1GB вільного місця
